🚀 Quick Start

① Build

docker build . -t docker-ubuntu-desktop

② Run

docker run -it --platform=linux/amd64 \
  -p 6080:6080 \
  docker-ubuntu-desktop

③ Open

http://YOUR_SERVER_IP:6080/vnc.html

«💡 Replace "YOUR_SERVER_IP" with your VPS/server IP.»

---
